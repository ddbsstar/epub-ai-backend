# Editorial typography v1

`POST /api/v1/books/:bookId/exports` accepts `{ "theme": "reader-editorial" }` with the existing owner session and idempotency header. This freezes `reader-editorial-v1`, engine `typographyProfile: editorial-1`, `ai: false`, and `process → validate → publish`. Explicit `ai: true` is rejected. Historical `reader-first` exports, illustration defaults, requests and published results keep their previous behavior.

The opt-in profile supports plain publisher prose with audited typography classes, heading tags, paragraphs, explicit quote/poem/caption/note markers, simple blockquotes, empty separators and inline emphasis. It generates source-bound positional CSS without editing body markup or text. Each source assignment records selector, role/source, source offsets and a hash. Unknown classes, inline styles, actual complex structures, meaningful conditional emphasis, unproved selectors or matched layout rules preserve the document and report why.

Admitted documents detach their original stylesheet links and attach one controlled stylesheet. The original CSS assets remain in the archive, subject to the separately audited unused-font-placeholder repair. Only original font/colour `:lang(...)` overrides may be deliberately replaced without inferring language; conditional emphasis/layout remain protected. Unused template classes no longer cause a whole otherwise ordinary essay to be rejected.

The design includes relative heading hierarchy, chapter-opening space, first-paragraph treatment, paragraph indents/spacing, quote margins in percentages and source-backed publication notes. Ordinary prose has no forced font size, line height, colour, background or nonzero horizontal body margins. Font embedding, arbitrary template support, semantic heading rewrites, TOC reconstruction, footnote repairs and reader-device certification are outside this version.

`summary.typography` optionally reports total/styled/preserved paragraphs, styled headings and role counts. Zero styled content is not described as visual improvement. Engine reports retain per-document skip reasons and exact assignment evidence.

On 2026-10-29 the private Wang Xiaobo source was independently validated: 39/43 documents styled, 335/342 paragraphs styled, 58 headings, 54 openings, 8 quotes and 29 source notes. Cover/TOC/copyright/image pages stayed protected. All original body bytes, six image bytes, navigation, metadata and reading order were preserved. The live loopback upload/export/download flow finished in approximately 11 seconds for this one 2.3 MB book, with actual EPUBCheck 5.4.0 zero errors/warnings. This is not a throughput or Kindle-device benchmark. No model was called. See the notes workspace `outputs/editorial-typography-1/` for private evidence; no source books belong in this repository.
