# 插画艺术配置与验收

当前新建小节转换使用 `subsection-inline-9` 和 `book-art-v1`，先执行 `art-plan`，再执行 `convert → assemble`。按用户要求，V9 显式冻结 `imageReviewMode:disabled`，不再执行生成后的 AI 视觉复核；无视觉模型配置也可运行，新费用不包含视觉调用。生成成功图经过来源、计划、回执、格式、哈希、锚点与最终 EPUBCheck 后即可插入，不以模型审美结论阻断。报告记录 `visualReview:disabled-by-request`，不伪造 PASS。细节见[当前转换契约](chapter-illustration-conversion.md)。

V9 保留 `content-people-1` 的生成前规划与提示规则；这些结构检查不等于生成后的 AI 看图。配置、请求和计价指纹隔离旧版缓存。旧 V4/V5/V6/V7/V8 任务保留原配置，可继续查询、看图和下载；不会自动迁移、改写旧拒绝、重发 UNKNOWN 调用或给旧图贴新版风格标签。下述 V7/V8 视觉门禁仅适用于相应历史任务，不再是新任务的前提。

## 人物要求一致性（V8）

V8 显式冻结 `planningPolicy:content-people-1`，使用独立的规划提示版本、配置和缓存。所选画面包含人物时，模型必须选择有来源依据的成年、安全场景并填写 `adults-only`；无人场景的场景描述和选中构思必须一致。程序在生图前检查明确的人物正向要求与 `no-people` 的冲突，错误码为 `ILLUSTRATION_PEOPLE_CONFLICT`。该有限词法检查处理否定表达与物件剪影，但不能证明所有隐含语义都一致，因此实际看图质检仍保留。

无人场景不再编译全书 `characterTreatment` 的人物画法，改用明确无人约束；艺术方案快照和哈希本身不变。新政策把场景字段上限从 110 调为 140 个 Unicode 码点、候选构图从 80 调为 100，完整提示仍限制 800，超限不截断。原 V6/V7 调用的边界、提示、哈希与封套保持，不能给旧构思添加新政策后复用旧结果。新政策进入配置、计划、源计划哈希、图像请求和私有质检绑定；公开质检仍只有结论、概要和五项理由。

## 历史自动视觉门禁（V7/V8，V9 不执行）

新转换须显式启用 `VISUAL_REVIEW_ENABLED=true`；关闭时免费目录仍可查询，但不接受新的转换任务，不回退成未审查生图。生成后，图片通过原有文件、来源、计划与锚点检查并复制到私有存储，章节进入 `REVIEWING`，再把本地图像的去元数据缩图与关联证据发送至配置的视觉模型。模型逐项检查原文依据、人物、媒介与色板、构图以及明显瑕疵；程序根据五项 `PASS/FAIL/UNCERTAIN` 计算 `PASSED/REJECTED/UNCERTAIN`。

只有五项均通过才将章节标记 `SUCCEEDED` 并允许插入。质量不通过或无法确认均标记 `REJECTED`，不返回图片预览地址；网页保留简短结论与五项理由。调用异常、超时或付费结果未知会终止该小节，后续小节可继续；不会自动重生图片或重发 `SENT/UNKNOWN` 审查。审查成功缓存与原书、章节、源计划哈希、艺术方案哈希、原图/缩图哈希、策略、模型和价格快照绑定，查询和刷新仅做本地读取。

完整审查结果和模型回执以私有 hash/size/reference 持久化。最终装配再次读取实际来源小节和冻结计划，核对原图完整性、源计划、段落锚点、艺术方案及完整审查绑定；仅信任进度中的 `SUCCEEDED` 字样不足以发布。报告只记录公开质量结论，不向网页泄漏私有路径、长原文或模型提示。

`counts.rejected` 与 `failed` 分开，纳入 `completed`。本次没有任何通过图片时，V7 仅发布可下载的转换/质量报告，不创建 EPUB；Run 的 `SUCCEEDED` 表示流程已完成，`partial:true`、`counts.succeeded:0` 与空 EPUB 地址明确表示没有插图成果。旧版本的零图失败语义保留。

计价快照纳入视觉模型、策略、Token 上界及配置价格，单节费用上界已经包含一次审查预估；目录额外的 `perChapterReviewUpperMicros` 只是费用拆分，不应再次相加。费用仍是配置估算而非供应商账单。默认 `VISUAL_REVIEW_MODEL` 为空时沿用 `QWEN_MODEL`，但实际服务必须支持图像输入；未做真实网关验证时不可声称已验证该供应商兼容。

这是有边界的自动模型判断，不是人类审美批准，也不能保证发现所有幻觉或确保全书人物一致。每本书艺术方向仍标为 `provisional`；方向上的 `visualReview:unreviewed` 表示整套视觉方案没有获人工批准，章节级 `visualReview` 独立记录实际图片质检。V7 没有新增用户必须审批的步骤。

## 内容驱动的本书艺术方案（V6）

上传与列目录不付费。点击转换后，程序对原书支持的小节均匀取最多 12 节，每节取首、中、尾最多 3 段，各最多 100 个 Unicode 码点。一次受账本保护的文本调用根据这些代表样本提出气质解读、选择理由与视觉配置。这是代表性采样，不是整本精读或自动找到“最佳画风”。选中小节的后续规划仍覆盖其完整正文，长节按已有 map/reduce 边界处理。

每本书可分别选择石墨轮廓、单色墨线、克制木刻、平面水粉、剪纸或水彩配线描，并确定 2–4 色色板、线条、形状、纹理、细节密度、留白和人物处理。字段有严格长度/枚举和来源绑定，不能输出任意 CSS、HTML、路径或可执行提示。全书保持同一个艺术方案，小节通过构图、距离、空间关系和节奏变化表达情感。

每个小节提出 2–3 项有真实段落依据的构思，记录选中项及理由。最终生图提示由代码从选中构思的主旨、构图、可见情感关系与具体场景编译，不能用无关的自由提示取代它。全部提示连同本书艺术包络在接纳文本调用成功前校验，最长 800 个码点；正文锚点不会早于选中构思的场景证据。

全书样本、方案、source SHA256、evidence SHA256 和语义方案哈希均写入仓库外私有文件。相同书籍和价格/策略下，换一批小节仍使用同一个全书艺术分析工作区；小节缓存同时绑定艺术配置哈希与方案哈希。成功结果可复用，SENT/UNKNOWN 不自动重发，风格升级不能复用旧图并冒充新版。整本分析的固定调用预估计入报价，新建任务与旧任务有独立版本指纹。

网页展示本书气质、采样覆盖范围、媒介、色板及理由，小节可展开查看构思与取舍。它不新增用户必须审批的步骤。以下 V6 的历史验收边界不包含后来新增的 V7 自动门禁；自动不合格重生或人物一致性模型仍未实现。参考案例用于构思与书页节奏原则，没有复制第三方技能或画家图像。

以下为保留的 V5 实现与验证记录，不是新任务的默认配置。

## 历史 V5 艺术方向

注册配置 `literary-editorial@2` 是原创、暂定的文学编辑插画方向：暖近白留白、炭灰手绘轮廓、石板灰和赭石的有限色板、平面色块与少量排线。全书固定媒介、色板、线条和细节密度；章节情绪通过构图、距离、疏密和明暗分布表达，不据此添加无来源对象，也不模仿具体艺术家。

这不是用户已批准某张历史样图，也不是强制回到被否定的三种媒介试样。目前仅有一个注册方向，没有实现自动判断一本书的最佳画风或人物一致性模型。

## 完整调用链

`注册快照及 SHA256 → 转换请求和任务配置 → 小节子操作及冻结 CLI 请求 → 文本规划输入 → 代码组装最终提示 → 生图请求指纹 → 计划与导出报告`

- 规划的 direct / map / reduce 输入使用同一快照。新规划请求、配置价格指纹和子操作与旧版分离，相同新版操作仍可复用成功结果。
- 最终生图提示由代码包裹固定艺术指令；文本模型返回场景不会取代固定规则。完整提示最多 800 个 Unicode 码点，超长拒绝，不截断场景。
- CLI 同时绑定编译后的艺术配置模块哈希。人工修改提示也必须保留艺术包络并通过检查，不能覆盖媒介或移除风格。
- 明确要求摄影、镜头效果、3D 渲染、特定作者模仿等冲突，在生图前以安全错误码拒绝。该检查是有界词法检查，不是完备的语义识别器。
- Worker 在生图前后验证风格快照、哈希、最终提示和计划回执。导出报告保留艺术配置与 `visualReview: unreviewed`。

## 验收边界

注册配置检查、提示检查、生成接口成功、EPUBCheck 成功均不能证明图片符合审美或准确表现原文。页面显示当前方向并明确其暂定状态；旧结果显示未锁定艺术方向。

实际图片仍需目视检查媒介、色板、笔触、对象关系、构图和阅读节奏。当前未实现自动视觉风格分类、视觉审批写回接口或自动不合格重生；不会把 `unreviewed` 改写为 `approved`。改变风格契约时应发布新注册版本，不修改历史配置或缓存绑定。
